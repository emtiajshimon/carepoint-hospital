How this works
• Your key is saved only in this browser (localStorage). It is never written into any project file, so it can never be pushed to GitHub.
• When you ask the AI chat a question, the browser sends the saved key to your own local server (POST /ask), which forwards it to ChatterMate.
• No key in Settings? The server falls back to the CHATTERMATE_API_KEY in your local .env file — which is ignored by git (.gitignore), so it is not pushed either.
• Never paste a real key into a file you plan to push to GitHub.
